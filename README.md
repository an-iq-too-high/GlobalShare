# How to run

First, git clone

```
git clone https://github.com/an-iq-too-high/GlobalShare
```

Second, cd

```
cd GlobalShare
```

Before you run it, say this

```
nohup python3 ~/GlobalShare/globalshare.py > ~/globalshare.log 2>&1 &
```

Then run it

```
python3 globalshare.py
```
